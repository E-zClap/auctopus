# Documentation

Start with the [project README](../README.md) for an overview and the [offline demo](../README.md#try-the-offline-demo) to see the workflow run. Choose a reading path below, or use the reference table for specific details.

## Researchers setting up an instrument

1. Use [Getting started](getting-started.md) to choose machines, transport and stages.
2. Describe your system's capabilities and operating rules with [Domain packs](domain-packs.md), then write study instructions with [Prompts](prompts.md).
3. Read [Safety](safety.md) for operating limits, approvals and agent permissions.
4. Connect the computational researcher and experimentalist with [Remote agents](remote-agents.md).
5. Follow [Running](running.md) to start, monitor and resume a run, then inspect its files with [Outputs](outputs.md).

## AI agent developers

1. Read [Workflow](workflow.md) for roles, stages and decisions.
2. Use [Prompts](prompts.md) for model inputs and reply contracts, and [Outputs](outputs.md) for file exchanges.
3. Read [Contributing](../CONTRIBUTING.md) for the code layout, checks and contribution process.

## Paper readers

1. Start with [The paper](paper.md) for the research question, findings and relationship to this release.
2. Follow [Workflow](workflow.md) to see how the implementation carries out the research process.
3. Read [Outputs](outputs.md) for the run-folder layout and records produced by the released engine.
